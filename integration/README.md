# 可选宿主适配开发资源

本目录不属于可安装的screen-assistance Skill，不是使用该Skill的前提。action_gate.py保留为宿主开发者的检查库；当前没有生产浏览器适配接入，不宣传它已强制保护运行中的助手。

库的check函数接收Action、当前与先前Observation，以及可选Confirmation，返回allowed/next/reason或consume_confirmation。调用者必须从真实工具和用户消息提供页面标识、修订号、目标状态与授权，不能由模型自报。

外发动作的scope_digest须覆盖动作、事项、接收方、关键内容和文件摘要。可使用会话内加盐摘要，避免保留敏感原文。调用者负责执行后立即消耗确认，超时也先查业务状态。该库不保存会话、不执行点击，不维护used状态；把它导入不等于完成集成。

未来适配验收须包含：真实页面修订变化时拒绝旧目标；文件或接收方变化后旧确认失效；一次外发后确认不能重用；工具回执与业务状态分别核实。tests/test_action_gate.py仅验证函数分支，不是这些浏览器集成测试。

既往预算、截图、模型失败与会话绑定问题保留在项目评测记录中。普通办事请求不需要阅读这些开发记录。
