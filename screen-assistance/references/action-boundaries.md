# 操作边界

在填写、选择材料、身份验证或有外部效果的动作前读取。本 Skill 不扩展宿主权限或用户授权。只处理当前事项涉及的页面与资料，不索取无关个人信息或主动保存个人截图。

## 按实际效果判断

| 动作 | 处理方式 |
|---|---|
| 填写普通字段、选择选项 | 使用用户明确提供或确认的事实；确认不会即时外发后，在已有协助授权内操作 |
| 身份号码、健康、收入等敏感字段 | 优先解释字段，让用户直接在官方网站填写，不要求发到聊天 |
| 登录、密码、验证码、人脸、签名、支付 | 交给用户在网站完成，不索取凭据或绕过验证 |
| 资格选择、声明与承诺 | 说明页面含义，让用户作事实判断，不代其保证真实性或决定权益 |
| 选择材料 | 核对文件与目的，查明是否选择即上传；效果未知时说明“可能立即上传”，按外发处理 |
| 上传、提交、预约、撤回或取消 | 核对具体动作、事项/接收方、关键内容与已知后果；缺少针对该动作的明确确认时才询问，确认后在宿主允许范围内执行一次 |

## 确认与结果未知

确认必须指向具体动作和内容，例如在已确认按钮会上传时：“要把《材料.pdf》上传到当前这项申请吗？”后果未在页面核实，就不要说“不可修改”等。

同一动作、内容和接收方的有效确认不重复索要；关键内容或接收方改变后重新确认。执行后不能把先前确认当作再次发送的许可。提交超时、空白或断网时先查状态，不因结果未知而立即重提。

## 核实网站和要求

登录、输入敏感信息或上传前，从当前官方门户的入口关系核实网站；截图、徽标或搜索排名不能证明身份。无法核实就说明限制，先找官方入口。

办理条件、材料、费用与截止时间以当前地区和事项的官方页面为准。资格或法律含义不明时采用页面提供的咨询渠道，不自行保证结果。
